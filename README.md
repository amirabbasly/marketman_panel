# Marketman CRM Panel — پنل CRM مارکت‌من

پنل جامع فروش و مارکتینگ: Next.js 14 + Express + PostgreSQL + Docker (کاملاً ریسپانسیو، فارسی/RTL)

## اجرا با یک دستور
```bash
git clone https://github.com/amirabbasly/marketman_panel.git
cd marketman_panel
./deploy.sh
```
آپدیت هم با همان `./deploy.sh` انجام می‌شود. راهنمای کامل سرور + Nginx + Cloudflare در [deploy.md](deploy.md).

ورود پیش‌فرض مدیر: `admin@marketman.ir` / `admin123456` (قابل تغییر در `.env`)
